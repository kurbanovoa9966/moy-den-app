# Мой день

Android-приложение для планирования дня: надиктуйте задачи голосом — Claude разложит их по времени и категориям (работа, дом, спорт, семья, личное).

- Ключ Anthropic API вводится в настройках приложения и хранится только на телефоне.
- APK собирается автоматически через GitHub Actions (вкладка Actions) и кладётся в ветку `apk`.
